# Helldivers 2 Super Destroyer names

Reference copy, kept because the pattern is a good model for procedurally naming
ships: a fixed service prefix, a concrete noun, and an abstract virtue joined by
"of". Nothing here is wired into the app — it's source material.

Every ship name in Helldivers 2 is built as:

    SES <first part> of <second part>

"SES" (Super Earth Ship) is fixed — the player doesn't pick it. **90 first parts
× 60 second parts = 5,400 possible names.** The name is chosen on first boot and
can be changed later from the ship's bridge.

## Sourcing caveat

These lists were assembled from search results, not read off the game or a wiki
page directly — this container's network policy blocks page fetches, so the
usual sources (the Helldivers wiki, Prima Games, GGRecon, the divers.gg
generator) could only be reached through search summaries. The counts agree with
the widely cited 90 / 60 / 5,400 figures, which is the main check available.

A few entries are spelled inconsistently across guides: "Conviviality" vs
"Convivialty", "Judgement" vs "Judgment". Before using any of this as literal
in-game data rather than inspiration, verify against the game.
